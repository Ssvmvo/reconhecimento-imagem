# Explicação do Código Refatorado

## Função calcular_soma_e_media

- Recebe uma lista de números
- Calcula a soma usando sum()
- Calcula a média dividindo pela quantidade de elementos
- Retorna um dicionário com soma e média

## Execução

- Define uma lista de números
- Chama a função
- Exibe os resultados formatados

## Benefícios

- Código mais legível
- Fácil manutenção
- Melhor organização dos dados
